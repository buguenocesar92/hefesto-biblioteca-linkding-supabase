# Oferta comercial
Hefesto Biblioteca: configuración inicial, importación de marcadores del cliente, taxonomía de etiquetas, capacitación y mensualidad de hosting/soporte/backup. Adecuado para agencias, consultores y equipos que recopilan referencias.

No duplica el acortador Hefesto Enlaces: aquí se organizan recursos; Shlink gestiona redirecciones y estadísticas. Tampoco es un gestor documental con OCR ni un LMS. Integración sugerida con Wiki/Academia: enlaces desde esos portales, con accesos acordados por separado.

Preferir instancia por cliente. Linkding tiene usuarios y opciones de compartir; no asumir permisos granulares por proyecto. Crear usuarios normales para trabajo diario; superusuario solo administración. Revisar de forma explícita perfil invitado, enlaces compartidos y permisos API antes de abrir acceso.

Cobrar implementación + servicio mensual según usuarios, importaciones y soporte. No se entregan precios ni garantías de capacidad sin medir costos y carga.

Proyecto Linkding bajo MIT. Imagen oficial sin modificar; kit añade configuración y scripts. Conservar avisos upstream. HTML snapshots de variante plus no incluidos; requieren mayor memoria/espacio y revisión separada.
